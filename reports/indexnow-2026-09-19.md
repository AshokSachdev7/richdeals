## Argument-mangling note (Git Bash)

Bare-slug mode was used rather than `--paths`, on purpose. MSYS rewrites any argument that
starts with `/` into a Windows path, so `--paths /offers` would have reached node as
`F:/offers`. Passing slugs without the leading slash lets the script prepend it inside
node, where MSYS cannot touch it. `MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*'` was also
set as a belt-and-braces guard.
