# RichDeals — 50-Post Traffic Plan (deep-research clusters)

**Why this shape, not 50-in-a-day:** the domain's whole problem is ~1,500 thin
pages Google refuses to index (Helpful-Content gate). Dumping 50 posts in one
day trips the spam signal and buries us deeper. Cap stays **4/calendar-day IST**.
50 posts → ~13 days. Depth + topical authority in a FEW clusters beats spray.

**Every post ships AEO + SEO + GEO:**
- **SEO:** real keyword research (SERP top-3 read) BEFORE writing; unique seoTitle
  ≤60ch + seoDesc 150-160; ≥1 real internal link to a live deal/hub; cover + alt.
- **AEO:** answer-first opening (the query answered in the first 2 sentences); a
  visible FAQ block (4-6 Q&As) mirrored in FAQPage JSON-LD; comparison tables.
- **GEO** (geo-rewrite-playbook, white-hat): citable standalone passages, concrete
  numbers/dates, "as of Aug 2026" freshness stamps, entity-dense, list/table
  structure engines quote. No fabricated facts.

**Execution:** existing BLOG cron + daily ticks pull the next unbuilt rows here,
3-4/day, newest-intent first. Mark `[x]` when live. Cluster order = ROI order.
